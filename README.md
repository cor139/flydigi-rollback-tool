# Flydigi Rollback Tool — 黑武士5s 固件回退工具

将飞智黑武士5s（Vader 5s）手柄的固件从 1.0.5.8 回退到 1.0.5.4（使用你自己的固件备份文件）。

## 适用范围

| 项目 | 要求 |
|---|---|

## 固件文件从哪来（三选一）

1. **本机自动检测**：程序启动时会自动查找 Flydigi 应用升级时留存在本机的备份
   （`%LOCALAPPDATA%\Packages\Flydigi.FlydigiSpaceStationForXbox*\LocalState\ota_*.bin`）
2. **手动选择**：界面上点 [选择固件...] 指定任意 `.bin` 固件文件
3. **仓库测试固件**：本仓库 `firmware/ota_v1.0.0.6.bin` 为 1.0.5.4 官方固件包，下载后手动选择即可
   （SHA256 `d75d18146a16a5671790bd31690e5b101bc9e2c6ebb26b71269c58618d35c655`，已实测可从 1.0.5.8 正常回退）

程序会解析固件容器内的版本号并在日志中显示，加载时校验 AOTA 文件头。

## 工作原理

飞智官方应用的固件升级流程是：向 `api.flydigi.com / testapi.flydigi.com` 查询最新固件版本 → 从返回的 URL 下载固件包 → 通过手柄通道刷写。

本工具在本地伪造这一流程：

1. 修改 hosts 把两个官方域名指向 `127.0.0.1`
2. 在本机 80/443 端口启动伪造的 OTA 服务器（TLS 证书为**运行时在本机随机生成**的自签证书，私钥不出本机，也不随程序分发）
3. 官方应用查询时会得到"版本 9.9.9.9 + 你所选固件地址"的响应，触发升级提示
4. 应用下载的即是你指定的固件文件，刷入手柄完成回退
5. 点"一键还原"撤销全部系统修改

程序对系统的全部临时修改（hosts / 受信任根证书 / UWP 回环豁免 / 防火墙规则）都可通过"② 一键还原系统"完全撤销。

## 使用方法

### 方式一：下载编译好的 exe

从 [Releases](../../releases) 页面下载 `FlydigiRollback.zip`，解压后右键"以管理员身份运行"。
exe 本身**不含固件**，首次使用按上面的"固件文件从哪来"准备一份。

> 部分杀毒软件可能对打包后的 exe 误报，介意的话请按下方命令从源码自行构建。
> 请核对 Release 附带的 SHA256 值。

### 方式二：从源码构建

```
pip install sv-ttk pyinstaller
pyinstaller --onefile --noconsole --name FlydigiRollback ^
  --collect-data sv_ttk ^
  src/flydigi_rollback_tool.py
```

### 操作步骤

1. 手柄用 USB 线或 Xbox 无线接收器连接到电脑
2. 运行程序，按提示加载固件（自动检测或点 [选择固件...]）
3. 勾选"我已阅读"，点 **① 一键启动劫持**（会弹窗二次确认）
4. 打开 Flydigi Space Station → 设置 → 固件版本，出现 **9.9.9.9** 的升级提示
5. 点确认升级，**刷写过程中不要断开手柄、不要让电脑休眠**
6. 手柄重启后查看固件版本（应显示 1.0.5.4）
7. **点 ② 一键还原系统**，否则 Flydigi 应用将无法联网

### 常见问题

- **端口 80/443 绑定失败（WinError 10013）**：程序会自动诊断。若是 Hyper-V/WSL2/Docker 的 winnat 端口保留会自动修复；若显示占用进程名（常见为 Clash/V2Ray 等代理），退出该程序后重试。
- **没有出现升级提示**：确认日志里"劫持已就绪"，且 Flydigi 应用是在本机运行（不是 Xbox 主机）。
- **升级失败**：把程序日志窗口截图反馈到 Issues。

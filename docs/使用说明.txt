 Flydigi 手柄固件回退工具 (1.0.5.8 -> 1.0.5.4)
═══════════════════════════════════════════════════

【适用机型】
本工具仅适用于 飞智黑武士5s (XBOX 授权版)。
本手柄仅支持 USB 有线连接。

【这是什么】
把 Flydigi Space Station 应用的固件升级请求劫持到本机,
让应用把"你指定的固件文件"当作"新版 9.9.9.9"刷回手柄,
实现版本回退。

【固件文件准备 (二选一)】
1. 自己的固件备份 .bin 文件
2. GitHub 仓库 firmware/ 目录提供的官方 1.0.5.4 测试固件
   ota_v1.0.0.6.bin
   SHA256: d75d18146a16a5671790bd31690e5b101bc9e2c6ebb26b71269c58618d35c655

【使用前提】
· Windows 10/11 电脑
· 已安装 [Flydigi Space Station For Xbox] 应用
  (商店 Official 版或 Dev 版均可)
· 黑武士5s 手柄用 USB 线连接到这台电脑 (仅支持有线)
· 手柄电量充足

【开始前必须关闭网络代理】
使用前请退出加速器、Clash、V2Ray 等一切网络代理/加速工具。
代理会接管应用的 DNS 和流量, 导致 hosts 劫持失效,
应用连不上本地服务器, 看不到升级提示或刷写异常。

【操作步骤】
1. 右键 FlydigiRollback.exe → 以管理员身份运行
   (直接双击也会自动请求管理员权限)
2. 加载固件: 把 .bin 文件拖进"固件拖放框", 或点击固件框
   选择文件 (程序会校验文件格式并显示固件版本号)
3. 点 [① 一键启动劫持], 等日志显示"劫持已就绪"
4. 打开 Flydigi Space Station 应用 → 设置 → 固件版本页面
5. 页面会出现 9.9.9.9 的升级提示 → 点击确认升级
6. 等待刷写完成, 手柄会重启, 查看固件版本号:
   显示 1.0.5.4 → 回退成功
7. 点 [② 一键还原系统] 恢复电脑原有网络配置
   (不还原的话应用将无法连接官方服务器!)

【注意事项】
· 使用前退出加速器 / Clash / V2Ray 等代理工具
  (最容易被忽略的失败原因)
· 刷写过程中绝对不要断开手柄、不要让电脑休眠, 否则可能变砖
· 本手柄仅支持有线连接, 用质量良好的 USB 线直连电脑,
  不要经过集线器
· 程序会临时修改以下内容 (一键还原会全部撤销):
  - hosts 文件: testapi/api.flydigi.com -> 127.0.0.1
  - 安装一张本机生成的自签证书 "Flydigi Fake OTA" 到受信任根
    (证书和私钥只存在于你自己的电脑上)
  - UWP 回环豁免 (checknetisolation)
  - 防火墙放行本机 80/443 端口
· 如端口绑定失败, 工具会自动诊断并尝试修复
  (常见原因: Clash/V2Ray 等代理软件占用, 先退出它们)
· 如升级提示失败, 截图程序日志窗口

Flydigi 黑武士5s 固件回退教程（简版）
======================================

准备
  1. 黑武士5s 手柄用 USB 线连接电脑 (本手柄仅支持有线)
  2. 电脑已安装 Flydigi Space Station 应用
  3. 固件文件 ota_v1.0.0.6.bin (仓库 firmware/ 目录下载)
     SHA256: d75d18146a16a5671790bd31690e5b101bc9e2c6ebb26b71269c58618d35c655
  4. 退出加速器 / Clash / V2Ray 等网络代理工具 (重要!)

步骤 (共 4 步)
  1. 管理员运行 FlydigiRollback.exe → 把固件 .bin 拖进固件框
     (或点击固件框选择) → 勾选"我已阅读" → 点 [① 一键启动劫持]
  2. 打开 Flydigi Space Station → 设置 → 固件版本 →
     会出现 9.9.9.9 的升级提示 → 点确认升级
  3. 等刷写完成、手柄重启 (期间不要碰手柄、别让电脑休眠!)
  4. 查看手柄版本显示 1.0.5.4 即成功 → 回工具点 [② 一键还原系统]

注意
  · 全程只花几分钟, 第 3 步千万别断开手柄, 否则可能变砖
  · 用完一定点"一键还原", 否则应用无法联网
  · 遇到端口占用报错, 先退出 Clash/V2Ray 等代理软件再重试
  · 仅适用黑武士5s; 仅供个人设备维护, 变砖概不负责
